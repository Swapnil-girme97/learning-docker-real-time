
# Docker Installation & Commands Interview Questions

## What is Docker Engine?

Docker Engine is the runtime responsible for building and running containers.

---

## Difference Between Image and Container?

Image:
- Blueprint
- Read-only

Container:
- Running instance of image

---

## What does docker run do?

Creates and starts a container from an image.

---

## Difference Between docker run and docker start?

docker run:
- Creates new container
- Starts container

docker start:
- Starts existing container

---

## What is Detached Mode?

docker run -d nginx

Runs container in background.

---

## What is hello-world image?

A lightweight Docker image used to verify Docker installation.
